# 粤拼记

看着粤语字，把粤拼打出来。句子从小块长成整句，连击和评级把重复变成还想再来一局，复习时间按 FSRS 记在这台电脑上。

远程仓库：<https://github.com/laurie-link/jyuping>

本地目录：`D:\jyutping-memo`

## 从句乐部借来的做法

句乐部（<https://julebu.ai/>）用键盘把英文句子一小块一小块拼出来，而不是背孤立的单词。粤拼记用同一套循环，记忆单位换成粤拼。

| 句乐部 | 粤拼记 |
| --- | --- |
| 看中文，打英文 | 看繁体字，打粤拼，声调用 1–6 |
| 初级拆词，中级从词组起，高级只打整句 | 同样三档，拆的是词，不是单个汉字 |
| Perfect / Great、连击、C 到 SSS | 一次打对、改对、声调改对，连击和评级照这个节奏 |
| FSRS 安排复习 | 卡片存在浏览器 `localStorage`，键名 `jyutping-memo:v1` |

固定说法按词整块练。「唔该」是一个词，不拆成「不」和「应该」。字下面有简体释义，答对后才显示粤拼和声调名。

## 怎么练

1. 首页点一课。初级、中级、高级和朗读开关在右上角「设置」里，默认不铺在首页上。
2. 看中间的字，把粤拼打在下面的横线上。一个音节一条横线。打的时候不判断对错，打完声调也不会自动跳到下一格。
3. 整题一次打对是 Perfect。删改后再对是 Great。先判错过、再改对，连击不断，但这题不再算 Perfect。
4. 按空格跳到下一格。每一格都写了东西之后，空格才判定对不对。左右方向键在横线之间移动。答对后看粤拼和声调名，再按一次 Enter 进下一题。显示答案之后，要照着把粤拼再打对一遍，才能往下。
5. 做完给得分和 C–SSS。新学的大约十分钟后再出现。答错的更早。已经记得住的会隔几天。

快捷键：

| 按键 | 作用 |
| --- | --- |
| 1–6 | 声调，写在当前横线里。打的时候不判断对错，也不会跳到下一格 |
| Space | 跳到下一格。每一格都有内容时，空格开始判断对错 |
| ← → | 在横线之间左右移动 |
| Enter | 和空格一样可以判断对错；答对并看完答案后，再按一次进入下一题。显示答案后，Enter 用来确认重打的粤拼 |
| Ctrl+' | 再读一遍 |
| Ctrl+; | 显示答案，这一题记为答错，连击中断。之后必须照着再打对，才能进入下一题 |

声音对照句乐部的四层，音效是自己合成的，朗读走微软的粤语语音，不用句乐部的音频文件：

- 打字时播放按键声。答对、改对、答错各有不同的提示音。连击到 3 次换成上行的连击音。打字过程中不播放「这一节对了」的声音。
- 答案露出来时自动朗读，包括答对和看答案。出题时朗读默认关掉，避免还没打就听到读音。
- 朗读用微软 Edge 的粤语神经网络语音晓佳（`zh-HK-HiuGaaiNeural`），语速放慢一成。需要开发服务器在跑，接口是 `/api/tts`。生成的音频在本机留 3 分钟，到点删除。接不上时才退回浏览器自带语音。

## 评分

基础分：Perfect 100，Great 80，改对 60，答错 0。连击从第 3 次开始加成：3 次 1.1，5 次 1.2，7 次 1.3，10 次 1.5，15 次 1.8，20 次 2 倍。

整课评级看加权正确率。几乎每题都是一次打对、而且没有答错，才是 SSS。一课里取历史最高评级。

## 复习

一课结束时，每个练过的音节各一张卡片，整句再加一张。同一张卡在这一课里多次出现时，只按最差的那次成绩写进 FSRS（`ts-fsrs`）。

第一次见到就 Perfect，先记成 Good，大约 10 分钟后再出现。已经复习过、再次一次打对，才记成 Easy，间隔会拉到几天。答错记 Again。

首页「今日复习」只拿出到期的卡片。没有到期时，会写下一张大概什么时候来。

进度也在同一份本地记录里：每课的最高评级、完成次数、连续天数、难度、音效、朗读开关。换浏览器或清站点数据，记录就没了。

## 课程

课程写在 `src/data/lessons.ts`。每个词只写繁体字和简体释义，粤拼不手填。页面加载时用 `to-jyutping` 按整词查出香港语言学学会粤拼，一字对一音，对不上就直接报错。同一个字在不同词里读音可以不同，所以查的是词，不是把字拆开各自取默认音。例如「呢個」是 `ni1 go3`，单字「呢」的默认音是 `ne1`；「聽日」是 `ting1 jat6`，单字「聽」的默认音是 `teng1`。

读音库是粤语计算语言学基础建设组（CanCLID）的 [to-jyutping](https://github.com/CanCLID/to-jyutping) 3.1.1，BSD-2-Clause。Copyright (c) 2024 Cantonese Computational Linguistics Infrastructure Development Workgroup. 软件按「原样」提供，不附带适销性或特定用途适用性的保证。

声母韵母声调：

1. 声母：十九个声母，每个一个例字
2. 韵母：不带鼻音、不带入声
3. 鼻音韵：韵尾 m、n、ng
4. 入声韵：韵尾 p、t、k
5. 声调：诗史试时市是，`si1`–`si6`

粤语口语常用字：说话里单独成字的那些，按用法分成小课，例如我你佢、语气词、量词。每字用 `to-jyutping` 查这个字本身的首选读音。有的字单用和放进词里读音不同，例如单独的「呢」是 `ne1`，「呢個」里是 `ni1`，这种差别写在答完之后的备注里。

常用三千词：按 rime-cantonese 语料里的出现次数，取两个字到四个字、并且收在粤语词库里的前 3000 个词。每 20 个词一课，每 500 个词再合成一档。点进这个板块还可以走「分类词汇」，把同一批词按饮食、身体、家人朋友、时间、交通、地方、钱、工作学习、感情再挑一遍。词序来自 Rime Cantonese 的 `essay-cantonese.txt`，CC BY 4.0，© CanCLID。词有普通话说法时，用开放词典的释义，CC BY 3.0，© 开放词典；没有单独释义的，释义就是这个词的简体写法。粤拼仍由 `to-jyutping` 现查，不采用词表里自带的拼音。

易混读音：把单独念和放进词里会变的字、以及声母韵母只差一点点的字放在一组。先打前一个，答完才看到和后一个差在哪里。

查字单独放在课程下面，不和课程卡片排在一起。输入字或词，看粤拼，也可以听。简体先用 OpenCC 转成香港繁体再查，和练习用的是同一套字。一个字查这个字本身；几个字连着打，按词来读，所以「呢個」是 `ni1 go3`，不是把「呢」单独念成 `ne1`。大字下面是这一处的读音，小字是词典里的其他读法。查字不写入练习记录。OpenCC 数据 Apache-2.0，转换程序 MIT。

## 听读 · 粤语歌词

首页的「听读」是独立板块，目前先有「粤语歌词」。输入歌名或歌手搜索，选中歌曲后逐行看歌词，每个汉字上方有粤拼和声调数字。页面上的字是简体，粤拼仍按香港繁体用 `to-jyutping` 整行来查；不认识的字标「·」。抄写模式一句一句显示粤拼，每格要写对才能用空格、Enter、右方向键或点击跳到后面的格子；可以返回前面的格子修改。练习模式不显示粤拼，仍按整句判断。按行末「朗读」可以听粤语语音，但不播放歌曲。

歌曲搜索和歌词来自 [LRCLIB](https://lrclib.net/docs) 的公开接口，页面只在用户搜索和选歌时请求，不在仓库中保存歌词。该目录并不保证收录每首粤语歌，搜索也可能返回其他语种的同名歌曲。自动标音无法保证覆盖歌曲里的变音和多音字，使用时请核对。断网或服务不可用时页面会给出提示。

入门必学：

1. 打招呼
2. 你同我
3. 食同饮
4. 问一句
5. 买嘢
6. 今日听日
7. 边个
8. 边度
9. 食咩
10. 买几多
11. 数字：一到十、二十、一百
12. 几点
13. 感觉
14. 讲礼貌

词典给一个词列出多个读音时，练习用它排在第一位的那个。例如「錢」的首选是变调 `cin2`，本调 `cin4` 排在后面，备注里写明这一点。
