# 粤拼记

看着粤语字，把粤拼打出来。句子从小块长成整句，连击和评级把重复变成还想再来一局，复习时间按 FSRS 记在这台电脑上。

远程仓库：<https://github.com/laurie-link/jyuping>

本地目录：`D:\jyutping-memo`

## 从句乐部借来的做法

句乐部（<https://julebu.ai/>）用键盘把英文句子一小块一小块拼出来，而不是背孤立的单词。粤拼记用同一套循环，记忆单位换成粤拼。

| 句乐部 | 粤拼记 |
| --- | --- |
| 看中文，打英文 | 看繁体字，打粤拼，声调用 1–6 |
| 初级拆词，中级从词组起，高级只打整句 | 同样三档，拆的是词，不是单个汉字 |
| Perfect / Great、连击、C 到 SSS | 一次打对、改对、声调改对，连击和评级照这个节奏 |
| FSRS 安排复习 | 卡片存在浏览器 `localStorage`，键名 `jyutping-memo:v1` |

固定说法按词整块练。「唔该」是一个词，不拆成「不」和「应该」。字下面有简体释义，答对后才显示粤拼和声调名。

## 怎么练

1. 首页选初级、中级或高级，再点一课。
2. 看中间的字，打粤拼。打出正确的声调数字，这一节就锁定，光标进下一节。
3. 整题一次打对是 Perfect。删改后再对是 Great。声调或拼写先错、再改对，连击不断，但这题不再算 Perfect。
4. 答对后先看粤拼和声调名，按 Enter 进下一题。
5. 做完给得分和 C–SSS。新学的大约十分钟后再出现。答错的更早。已经记得住的会隔几天。

快捷键：

| 按键 | 作用 |
| --- | --- |
| 1–6 | 声调，并确认当前音节 |
| Enter | 提交；看完答案后进入下一题 |
| Ctrl+' | 用粤语把当前的字读出来 |
| Ctrl+; | 显示答案，这一题记为答错，连击中断 |

朗读只在系统里能找到粤语语音（`zh-HK`，或名称里带粤语 / Cantonese）时才出声，避免落到普通话。

## 评分

基础分：Perfect 100，Great 80，改对 60，答错 0。连击从第 3 次开始加成：3 次 1.1，5 次 1.2，7 次 1.3，10 次 1.5，15 次 1.8，20 次 2 倍。

整课评级看加权正确率。几乎每题都是一次打对、而且没有答错，才是 SSS。一课里取历史最高评级。

## 复习

一课结束时，每个练过的音节各一张卡片，整句再加一张。同一张卡在这一课里多次出现时，只按最差的那次成绩写进 FSRS（`ts-fsrs`）。

第一次见到就 Perfect，先记成 Good，大约 10 分钟后再出现。已经复习过、再次一次打对，才记成 Easy，间隔会拉到几天。答错记 Again。

首页「今日复习」只拿出到期的卡片。没有到期时，会写下一张大概什么时候来。

进度也在同一份本地记录里：每课的最高评级、完成次数、连续天数、难度、音效、出声提示。换浏览器或清站点数据，记录就没了。

## 课程

课程写在 `src/data/lessons.ts`。每个词的字数必须和粤拼音节数一致，对不上时页面会直接报错。

1. 六个声调：诗史试时市是，`si1`–`si6`
2. 打招呼
3. 你同我
4. 食同饮
5. 问一句
6. 买嘢
7. 今日听日

口语变调写在句子备注里，例如「钱」的本调是 `cin4`，口语记 `cin2`。
