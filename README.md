# 粤拼记

看着粤语字，把粤拼打出来。初级会把句子拆开再拼回去，连击和评级推动重复，复习时间按 FSRS 记在这台电脑上。

```bash
npm install
npm run dev
```

打开终端里的本地地址。输入法切到英文，声调用数字 1–6。

首页「听读 → 粤语歌词」可以搜歌名或歌手，从 LRCLIB 读取歌词，并在每个汉字上方显示自动生成的粤拼。点「朗读」可听该行的粤语语音；这里不播放歌曲。

首页「互译」可在普通话与粤语白话之间切换。优先查本地常用词库；未收录的短词和整句自动走服务器端 DeepSeek 接口。译文可切换简繁、复制，并显示粤拼和朗读粤语。将 `DEEPSEEK_API_KEY=你的密钥` 写入项目根目录的 `.env.local`（Git 已忽略），开发服务器会读取它。正式部署把密钥放在服务进程的环境变量中，参见 [Linux 部署说明](docs/Linux部署.md)。

说明见 [docs/项目说明.md](docs/项目说明.md)。每天的任务、方向和修 bug 记录在 [开发](开发/README.md)。
